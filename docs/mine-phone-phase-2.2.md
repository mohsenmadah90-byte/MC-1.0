# Mine Phone Phase 2.2

- Dashboard entry item changed from named paper to `mcity:mine_phone`.
- Mine Phone use requires a valid Personal Card in the player's inventory.
- Paper named `menu` is no longer recognized or accepted as a Dashboard entry item.
- Spawn/recovery delivery now gives Mine Phone.
- Settings/help text was updated from Menu Paper/Dashboard to Mine Phone.
- Existing paper items are not deleted; they simply no longer open MCity.
- Existing money, level, player, and database data is untouched.

A valid card is checked using the phase 2.1 card registry/signature service. Mine Phone UI opening and card authentication are now connected; ATM/Gate access remains phase 3.

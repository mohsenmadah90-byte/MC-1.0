# ATM Appearance Phase 3.2

- Added three MCity ATM blocks based on the supplied Economy Plus ATM models/textures:
  - `mcity:wall_atm`
  - `mcity:floor_atm`
  - `mcity:floor_atm_bottom`
- Added MCity block tags and configured ATMProtection to recognize the variants.
- Added supplied geometry and texture assets under the MCity Resource Pack namespace.
- ATM setup hooks can configure the visual ATM variants; card authentication remains active before ATM UI opens.
- ATM economy, raw inputs, prices, journal and recovery remain unchanged.

Gate visual blocks were not invented in this phase because no Gate assets were supplied; Gate authorization registry from phase 3.1 remains ready for later Gate assets.

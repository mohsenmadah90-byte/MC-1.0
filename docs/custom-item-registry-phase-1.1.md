# Custom Item Registry — Phase 1.1

Added the canonical registry for the future MCity identity system:

- 16 colored `mcity:personal_card_<color>` definitions.
- `mcity:mine_phone` definition.
- Stack size 1 for all identity items.
- Market and contract disabled by policy.
- Identity requirement enabled.
- Versioned texture keys and paths.
- Central lookup methods for cards, colors, custom items and Mine Phone.

No recipes, item JSON files, Resource Pack files, or gameplay handlers were added in this sub-phase. Those belong to phase 1.2 and phase 2 after the custom icons are supplied.
